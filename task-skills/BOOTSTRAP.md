# Task skill discovery

This is an explicitly selected task catalogue, not a default replacement for legacy clients. Use a compatible IDE/CLI with safe retirement and effective-payload resolution.

The project AGENTS locates its CLI; the IDE Host provides authenticated skills.list/skills.resolve/skills.read. Choose a task by its whenToUse. For CLI use skills list and skills resolve; skills read intentionally reads the official cache. Resolve project, then global, then catalogue and keep body/attachments/scripts on one root and contentHash. Missing or broken high-priority copies are errors, not permission to ignore local edits.

A raw external SDK session with no CLI, installed skills or Host has no automatic catalogue discovery. Use the actual SDK help for supported local work or establish IDE/CLI integration. Do not silently download software to manufacture a discovery path.
